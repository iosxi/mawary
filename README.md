# mawary

スマホの**背面が向いた方角に何があるか**を出す Android アプリ。
画面の真ん中は方位盤で、**中心が自分**。枠だけの線で描くので軽い。

- 対応: Android 9 (API 28) 〜 最新 (targetSdk 36 / Android 16)
- 出来上がり: `mawary.apk` — **約 39 KB**
- 要求する権限: **`INTERNET` と `ACCESS_FINE_LOCATION` の 2 つだけ**
- 依存ライブラリ: **無し**（AndroidX も Play 開発者サービスも使っていない）

> **実機で確認済み。** Sony XQ-FS44 / Android 16 (API 36) に入れ、実際の現在地で
> 周りの店や施設が出るところまで見ている。測った値は下の「実測」に載せた。

地図を見るためのアプリではない。**スマホを向けた先に何があるかだけ**を、
歩きながら一目で読めるように出す。

## 画面

上から順に。

- **方位の読み**（大きい数字）— 背面が向いている真方位と、その 16 方位名。
  下の帯は方位テープで、真ん中の鉤が今向いている先。
- **方位盤** — 中心が自分。上が**背面の向き**なので、画面の上に出たものが
  「今向いている先にあるもの」。輪は距離の目盛りで、外側が現在のレンジ、
  中がその 2/3。中心から斜めに伸びる 2 本の線が**視野の範囲**（左右 25 度）。
  - 視野に入ったものは**濃い菱形**で、名前と距離を横に出す。
    同じ方角に重なったときは縦にずらし、引き出し線で元の印と結ぶ。
  - 視野の外にあるものは**薄い菱形**。レンジより遠いものは輪の外側に
    短い目盛りだけ出す（方角は分かるように）。
- **一覧** — 視野に入っているものを近い順に 3 つ。名前と距離、それに
  `<` `>` `|` で**どちらへ振れば正面に来るか**。

**画面を叩くと距離レンジが変わる**（200m → 500m → 1.0km → 2.0km → 200m …）。
**長押しで Google Places の API キー**を入れる欄が出る。

画面は消灯しない。回転もしない（縦固定）。

## 背面の方角の出し方

このアプリの肝。**傾けても読みが飛ばない**ようにしてある。

素直に作るなら、端末の -Z 軸（背面カメラが覗いている向き）を水平面に落として
方位を取る。ところが**スマホを寝かせると -Z は真下を向く**ので、水平成分は
ただの雑音になる。よくある対処は「傾きが閾値を超えたら +Y 軸（上端の向き）に
切り替える」だが、**切り替わる瞬間に読みが飛ぶ**。

mawary は閾値を使わない。**-Z と +Y の水平成分を、正規化せずにそのまま足す**。

- 立てて持つと -Z がほぼ全部を担い、+Y は真上を向くので水平成分がほぼ 0。
- 寝かせると役割がそっくり入れ替わる。
- その中間では**両方とも同じ方位を向く**ので、足して困らない。

正規化しないことが、そのまま「水平に寝ている軸ほど強く効く」重み付けになる。
2 軸は直交しているので**同時に真上を向くことはなく**、和が消えることもない。
（[`Geo.backAzimuth()`](app/src/main/java/com/mawary/Geo.java)）

**実測で裏を取ってある。** 姿勢行列を組み立てて JVM で回し、

- 手で組んだ 4 姿勢（立てて北 / 立てて東 / 寝かせて上端が北 / 寝かせて上端が西）が一致
- 方位 7 通り × 傾き 7 通り = **49 通りすべてで、狙った方位を 0.5 度以内で復元**
- 立てた状態から寝かせるまで 0.5 度刻みで掃いて、**隣り合う読みの差の最大が 0.0000 度**
  （＝どこにも飛びが無い）

読みは角度そのものではなく**単位ベクトルのまま平滑化**している（時定数およそ
120 ms）。359 度と 0 度をまたぐときに暴れないため。

方位センサが校正されていないときと、端末を寝かせすぎているときは、
画面の下にその旨が出る。

## どこから「モノ」を取るか

**Google Places API (New) の Nearby Search が本命。** キーを入れると
Google マップの検索結果がそのまま出る。キーの渡し方は 2 通り。

- `local.properties` に `MAWARY_PLACES_API_KEY=AIza...` と書いてビルドする
- **アプリを長押し**して欄に貼る（端末内に保存され、次からはそれを使う）

**キーが無いとき、および Google が断ったときは OpenStreetMap（Overpass API）に
落ちる。** キーが要らないので、入れたその場で動く。どちらから取ったかは
画面の右上に出るので、見間違えることはない。

Overpass は混むと落ちるし、詰まる。実際に開発中、同じ端末から
`OSM: timeout` を何度か食った。そこで**ミラーを 3 つ順に試し**、
全部だめなら **15 秒後に自分で取り直す**。読み待ちは 25 秒
（Overpass 自身が最大 20 秒かけるため、それより短いと必ず先に切れる）。

取りに行くのは、**前回から距離レンジの 1/4 以上動いたとき**か、
**前回の答えが 2 分より古くなったとき**だけ。通信は最低優先度のスレッド 1 本。

## 実測

Sony XQ-FS44 / Android 16 (API 36) で測った値。

| 測ったもの | 値 |
| --- | --- |
| APK の大きさ | **38.7 KB** |
| 冷えた状態からの起動 (`am start -W` の TotalTime) | **89 ms** |
| 描画 50 パーセンタイル | **6 ms** |
| 描画 99 パーセンタイル | **8 ms** |
| 引っかかった frame | **658 枚中 1 枚 (0.15%)** |
| Missed Vsync | **0** |
| GPU 50 / 99 パーセンタイル | **3 ms / 4 ms** |
| メモリ (TOTAL PSS) | **約 63 MB** |
| 周辺 40 件の取得 (Overpass) | **4.4 〜 7.8 秒** |

方位センサは 50 Hz で届くが、画面は 60 Hz でも余っている。

## 軽いことの中身

- **`onDraw()` で確保しない。** Paint も Path も文字列も、元になる値が
  変わったときにだけ作る。距離と方位は**自分が動いたときにだけ**計算し直す
  （方位センサが 50 Hz で動くのに対し、現在地はたまにしか変わらない）。
  距離の文字列（`84m` / `1.2km`）も同じときに作り置きする。
- **塗らない。** 塗りも影もグラデーションも無く、線と短い文字列だけ。
- **ライブラリを足さない。** 通信は `HttpURLConnection`、JSON は Android に
  入っている `org.json`、現在地は `LocationManager` を直に使う。
  そのぶん APK は 39 KB で済み、起動に読み込む物も無い。
- 画面を離れると**センサと位置の購読を両方切る**ので、裏に回ると何もしない。

## 権限について

要るのは 2 つだけ。

- **`INTERNET`** — 周りに何があるかを尋ねるため。
- **`ACCESS_FINE_LOCATION`** — このアプリは方位と距離しか出さないので、
  現在地がずれると**全部の印がずれる**。おおよその位置は街区ひとつ分の幅があり、
  レンジ 200m では使い物にならない。

`ACCESS_COARSE_LOCATION` は**宣言していない**。Android 16 で実測したところ、
`ACCESS_FINE_LOCATION` だけを宣言しても許可ダイアログには
「正確な位置 / おおよその位置」の両方が出て、**「おおよその位置」を選ぶと
宣言していない `ACCESS_COARSE_LOCATION` の方が付与される**。
そのため、おおよその位置しか貰えなかった場合もアプリは動くようにしてある
（印の位置はそのぶん甘くなる）。

位置情報を外へ送るのは**周辺検索の問い合わせだけ**。履歴も保存しない。

## 作り方

Android SDK (platform 36 / build-tools 36) と JDK 17 が要る。

```sh
# 署名鍵を作る（初回だけ）
keytool -genkeypair -keystore keystore/mawary.jks -alias mawary \
        -keyalg RSA -keysize 2048 -validity 10000 \
        -storepass <パス> -keypass <パス> \
        -dname "CN=mawary, OU=mawary, O=mawary, C=JP"

# keystore.properties を置く
#   storeFile=keystore/mawary.jks
#   storePassword=<パス>
#   keyAlias=mawary
#   keyPassword=<パス>

./gradlew assembleRelease
```

出来上がりは `app/build/outputs/apk/release/app-release.apk`。
`keystore/` と `keystore.properties` と `local.properties` は
リポジトリに入れていない。
